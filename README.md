# PulseTwin AI

An interactive **synthetic** cardiovascular wellness digital-twin proof of concept for the Happiest Health CRP Digital Twin Challenge 2026.

> **Educational prototype only.** No real patient data, no clinically validated model, and no disease prediction. Do not use for diagnosis, treatment, or healthcare decisions.

## Features
- Eight adjustable fictional patient measurements
- Deterministic synthetic dataset (2,400 records)
- Random Forest trained to reproduce a **fabricated formula-based label**
- Illustrative score and holdout agreement with synthetic labels (NOT clinical accuracy)
- Seven-day simulated wearable history and CSV export
- Model feature importance and simple illustrative rule flags

## Run on Windows 11
Open this folder in VS Code, then in **Terminal > New Terminal**:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

This approach does not require activating PowerShell scripts. Python 3.10–3.12 recommended. If `py` is not found, install Python from python.org and enable its launcher.

## Limitations
The label is generated by an arbitrary formula, not clinical ground truth. The model is not validated on real patients. Its displayed score is not a calibrated medical risk estimate. The 7-day timeline is randomly simulated. No external data or device integrations exist.
